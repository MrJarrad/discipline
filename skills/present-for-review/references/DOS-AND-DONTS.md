# Do's and Don'ts — present-for-review

---

## Do

| Do | Why |
|----|-----|
| Quit Capture fully, relaunch `/Applications/Capture.app`, then: *Ready to look. Hairline is off the pills; same fill. Check the bar edges.* | The running signed app is the review surface |
| Wait until the process is gone before relaunch | A stale process is a lying review |
| Web: *Ready to look. Hairline is off the pills. [jarrad.design](https://jarrad.design)* — one markdown hyperlink in the same chat message | Operator opens the link themselves — no extra windows |
| Block present when Capture is mid-recording | Do not destroy an in-flight recording |
| Say Mac parent must present native when this session is Cloud / no Mac | Cloud cannot quit the operator's app |
| Keep the ready note to what changed + what to check | Operator is a designer — outcomes, not machinery |

---

## Don't

| Don't | Why |
|-------|-----|
| *The hairline pass is in Applications — it isn't signed off until you've looked.* | Sending the operator to find the build is homework |
| Open a new Browser tab/window as the web present step | Operator does not need a thousand new windows to close |
| Dump a screenshot as the operator review packet | A screenshot is not the presentation |
| Open `mac/.build/.../Capture` instead of the signed bundle | Unsigned dev build is not operator sign-off |
| Say "go look at localhost" or "check Applications" | Present means quit+relaunch native or hyperlink-in-chat for web |
| Present before reviewer PASS (or ux-designer when feel) | Agent review cycle must finish first |
| Present a partial when the locked table was wider | Partial ≠ the agreed update — spec incomplete |
| Substitute a PR link or diff for the live product | Operator visual sign-off is the running product |
| *Nothing else until you look* or hard-refresh homework | Web present is one markdown hyperlink — operator is never mute |
