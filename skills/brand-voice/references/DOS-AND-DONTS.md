# Do's and Don'ts — brand-voice

## Do

| Do | Why |
|----|-----|
| Load [HOUSE-VOICE.md](HOUSE-VOICE.md), then the project's voice guide | The house voice is the floor; the guide adds project specifics |
| Pin a derived voice on traits, person and formality, lexicon, register range, and surface it | A named voice beats an improvised one |
| Flex register by the surface's job, hold who the brand is | Same brand, different volume |
| Lead with the benefit, then the feature | The reader gets something before the mechanism |
| Name the trait each key line delivers, after reading it aloud | Copy is verified by ear, not a silent skim |
| Extend the guide when it misses a case, then write | A one-off tone is a bug |
| Open with what the person loves and makes, not their title | Warmth over mechanics, rule 1 in [HOUSE-VOICE.md](HOUSE-VOICE.md) |
| Let sentences run and join, and vary their length | Rule 2: copy that reads like a person talking |
| Use considered, quiet, crafted or exceptional where it is true | Rule 3: honest feeling, not filler |
| State one belief per paragraph | Rule 4: a belief lands; an explanation lists |

## Don't

| Don't | Why |
|-------|-----|
| Restate the house voice in a project guide | One source; the guide carries only what is specific to the project |
| Use a word on the house banned list | The list is the lexicon floor for every project |
| Add intro clauses or meta-commentary | The no-meta-commentary rule and its examples live in [HOUSE-VOICE.md](HOUSE-VOICE.md) |
| Claim a superlative or "#1" you cannot back | Every claim true and specific |
| Use vibe words in place of the specific | "Powerful" and "next-level" show nothing |
| Stack three verbs or three abstract nouns in a row | Rule 2: it reads mechanical |
| Use workplace words: align, iterate, steer, production, deliver | Rule 5: they sound like a status report |
| Strip a true feeling word as if it were padding | Rule 3: the aim is to stop mechanical copy |
| Apply this to operator chat or agent output styles | Scope is published copy |
