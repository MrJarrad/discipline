# routing — the domain-library table

Which skills a brief must name once a domain is in play. A lookup consulted while writing
the brief, not a decision made inline — SKILL.md points here. Nothing was rewritten; this
is the 1.78.0 table, moved, carrying the 1.79.0 rows for the previously unrouted skills.

## Domain-library table (which skills the brief must name)

| Domain in play | Load |
|---|---|
| SEO / meta / sitemap / schema / rankings | the relevant `seo-*`; `seo-audit` before any launch |
| Shipping web UI | design-system, design-craft, markup-standard, quality (Law 9 lab CWV), webapp-testing |
| Next.js (App Router, "use cache", OpenNext, RSC) | nextjs + next-devtools-mcp, plus workers-best-practices/wrangler |
| JHD web UI (tokens, Action, theme, conformance) | design-system (house `@jhd/design-system`) |
| New JHD product / new GitHub remote | new-product |
| Workers / Pages / KV / D1 / R2 / wrangler | workers-best-practices, wrangler (+ durable-objects, agents-sdk, sandbox-sdk, cloudflare-email-service) |
| Auth, input, payments | quality + code-minimalism safety floor — not a separate OWASP skill |
| Image generation | banana · editing an existing image: qwen-edit |
| Brand video / motion content | remotion, ffmpeg, playwright-recording, elevenlabs/acestep, runpod |
| Apple platform project | the Apple suite (swift/swiftui/ios/macos, testing, security, release-review) — never cross-load with web |
| Meetings / ops, transcripts | ops-inbox, which chains summarise-meeting |
| Prior decisions, learnings | vault-recall before deriving; vault-write to land |
| Requirements still forming | discover-scope |
| Shape a settled idea, or stress a plan | shape-stress (chains grilling) |
| Colliding terms; operator corrects a part name | define-terms |
| User-facing copy | brand-voice |
| Changing the skill library or agent charters | agent-ops (eval gate) + skill-authoring (the writing) |
| Non-trivial build/design before dispatch | grilling (frontier empty or explicit skip) |
