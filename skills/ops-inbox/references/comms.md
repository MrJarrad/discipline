# Comms rules — communicating as/for Jarrad

## Principles (research-backed, banked 2026-07-27)
- BLUF: conclusion/ask in the first line, context after.
- One ask per message, named to a person, with a time.
- Outcomes not activity ("Client share delivered Fri", not "worked on share").
- Every risk carries its mitigation. "None" is written explicitly, never omitted.
- 30-second readable; thread or link the detail.
- Silence is a signal you don't control: "no change, next update Fri" beats skipping.
- Tailor per audience: team gets detail, client gets outcomes + decisions needed.
