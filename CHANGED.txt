1.74.0 — handoff-to-code: the export pair is the contract (2026-09-10)

New skill `skills/handoff-to-code/SKILL.md`. Where 1.73.0 made the brief point at a
Design Handoff export instead of re-describing it, 1.74.0 gives the doer the procedure:
**the handoff pair is the contract — every node, token, copy string and annotation in it
is built, never Figma pixels, never inferred values.** Six steps: reconcile the
markdown's companion `state`/`content` hashes against the JSON's
`fingerprint.designSystemStateHash`/`contentHash` and its `schemaVersion` against the
consumer's declared versions (a mismatch is a stale-pair defect, not a build); run
`handoff-css --config … --check` and read every warning in the report's
`Responsive classes (P11) and aliases (P12)` section — `VIEWPORT_UNFLAGGED`,
`VIEWPORT_OUTSIDE_GROUPS`, `VIEWPORT_CLASS_WITHOUT_FRACTION`,
`VIEWPORT_FRACTION_DISAGREES`, `BUILD_CELL_CONTRADICTORY` — building *through* a warning,
never around it; map every `$variable` through its **`codeSyntax.WEB`** name, where no
emitted token is a defect and a legacy alias is not the name; implement with the
handoff's **Build standards 1–5** as the mechanism rules (a `[Grid]` frame is
`display: grid` and `col-span(N/M)` is `grid-column: span N` — column maths is a defect
even when it measures right); build the Content Outline verbatim, with `⚠ placeholder` a
defect rather than a guess and the newest pair beating any prior record; return the
deviation table `element · Figma binding · token used · value · status · ruling ref` and
**stop for a ruling on drift**. Worked example is the real 2026-09-10 nav footer
(`$device/screen-height/full` → `height: var(--device-screen-height-full)`).

`capture-figma` hands over: `## Export shape` and the values pass now point at
`handoff-to-code` when a pair exists; it keeps the read-order law, the lanes, the copy
and template-layout lanes, and recapture. `dispatch-brief`'s Source contract and
`agents/engineer.md`'s stack name the skill as the doer's, and the engineer's evidence
return names the per-node form of the deviation table.
`hooks/scripts/source-contract-law.test.mjs` gains 9 assertions on the new ratified
sentences, including that the skill reads standalone — no machine-local paths, house
names only under `## At JHD` — because the same skill ships to Figma Community inside
the `handoff-css` package (`skills/handoff-to-code/SKILL.md` there).

component names." The operator corrected this: it doesn't matter whether
the thing is a layer in Illustrator or Figma, or a class or style in code

things. Every thing already has a name where it's defined — a layer,
component, class, token, style, file, or variable — and that name is the

is reworded to name its architecture map as one source among several

not the source.

1.70.1 — vocabulary is layer names, not the operator's word (2026-09-08)

1.70.0's part-name fidelity rule framed the canonical term as "the

`issue-triage`'s part-name resolution both quote the layer name verbatim,
with the code identifier (where added) mirroring it. `capture-figma` gains
a short note that its architecture map's layer list is define-terms's
vocabulary source. `output-styles/discipline.md` states the vocabulary is
the source file's names, not a paraphrase.

1.68.0 — review/loop stage redesign (2026-09-07)

The reviewer stops being the merge gate and becomes an informer: severity-ranked
findings (red blocks / amber is a call / note is no action), each independently
re-validated before it surfaces. Merge = deterministic gates green + no red
finding open, remitted by the parent. Review rounds are hard-capped at 3 per
change; at the cap the loop halts and the open findings go to the operator.
LIGHT becomes the standing review tier and FULL the exception a brief must
argue; the no-tier fallback inverts from FULL to LIGHT; small fixes ship with no
reviewer. Deterministic gates must be green before a reviewer is solicited. The
reviewer reads the live lock file and reds a drifted spec. Look is the operator's
lane — for UI work the preview link goes out at engineer-done and never waits on
review. Adds the notes-ledger rule (append before compaction, re-read after) and
an effort tier field (routine | contested | high-stakes) mapped in model-routing.
ux-designer is realigned to the same law — visual evidence is agent-internal, the
baton returns to the parent, and ready is the merge condition rather than a review
verdict. A plugin-wide, newline-tolerant test sweeps every shipped doc for the
stale phrasing.
